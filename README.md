# IG-Wizard

IG-Wizard is an all-in-one study companion for IGCSE & IAL students. It combines a searchable past-papers library with an AI-powered tutor to help learners prepare more efficiently and understand difficult concepts faster.

🔗 Live site: https://www.igwizard.tech/

---

## Features

-  **Past Papers Library** — Browse and search exam papers and mark schemes by board, subject, year, and session.
-  **Smart Search** — Quickly find the exact topics or questions you want to practice.
-  **AI Tutor** — Get instant, context-aware explanations for questions you’re stuck on.
-  **Fast & Modern UI** — Built to make studying smoother, not painful.

---

## Why IG-Wizard Exists

Most students waste time digging for the right questions instead of actually learning. IG-Wizard fixes that by putting everything in one place — and giving you an AI tutor on top.


## Getting Started (Local Development)

1️⃣ Clone the repository
git clone https://github.com/iiVertex/IG-Wizard.git

2️⃣ Install dependencies
cd IG-Wizard
npm install

3️⃣ Run the development server
npm start
http://localhost:3000

## Usage
Open the Past Papers section to browse and filter exam resources.

Use Search to jump straight to the topics you care about.

Open the AI Tutor to get explanations and step-by-step guidance.
